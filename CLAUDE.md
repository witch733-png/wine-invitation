## Project Overview

A static single-page HTML invitation for the IWA 5 Gala Dinner (리샤르 조프루와 갈라디너) at 신라호텔 아리아케. No build system, no dependencies, no framework.

## Development

Open `index.html` directly in a browser — no server or build step required.

## Architecture

The entire site is `index.html`: inline CSS in `<style>`, static Korean-language content, and a placeholder RSVP button with no attached functionality.
