## Project Overview

A single-page static HTML invitation for the IWA 5 Gala Dinner (Richard Geoffroy, Hotel Shilla Ariake). Content is written in Korean. No build system, no dependencies, no framework.

## Development

Open `index.html` directly in a browser — no server, build step, or install required.

## Architecture

The entire project is `index.html`: inline CSS in `<style>`, static Korean-language content, and a placeholder RSVP button with no JS wired up yet.
