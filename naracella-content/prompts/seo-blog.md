# SEO Blog 작성 기준 (seo-blog.md)

## 파일 상단 필수 메타

```
slug: [URL에 사용할 영문 소문자 슬러그]
meta-description: [120자 이내, 검색 결과에 표시될 문장]
search-intent: [informational | commercial | transactional | navigational]
```

## 문서 구조

```
# H1 — 핵심 키워드 포함, 클릭을 유도하는 제목 (1개)

[AI 요약 블록] — 150자 내외, 독립적으로 읽히는 단락. AI Overview·피처드 스니펫 최적화.

## H2 — 본문 섹션 (2–5개)
### H3 — 세부 항목 (필요 시)

## FAQ
Q: ...
A: ...
(3–5개)
```

## 작성 규칙

- 단락은 3–4문장 이내 (모바일 가독성)
- 키워드는 자연스럽게 녹이되 반복 금지
- 주관적 평가에는 근거(빈티지, 생산자, 점수 등) 명시
- 전문 편집자 톤 — 광고 문구·과장 표현 금지
- 한국어 문장은 번역체가 아닌 자연스러운 흐름으로

## 금지 표현

- "최고의", "혁신적인", "독보적인" (근거 없는 수식)
- "이 와인은 정말 특별합니다" 류의 빈 감탄
- 동일한 문장 구조 반복
