# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

Content workspace for Naracella — a premium wine brand. All writing targets Google SEO and GEO/AI Overview optimization in Korean.

## Directory Layout

- `blog/` — long-form Korean blog posts
- `seo/` — keyword research, slug lists, search intent notes
- `prompts/` — reusable writing prompts for consistent output

## Content Rules

### Structure
- Use H1 / H2 / H3 headings in every piece.
- Every article must include an FAQ section and an AI summary block (a short, self-contained paragraph optimized for AI Overviews and featured snippets).
- Each piece needs a slug, meta description, and explicit search intent label (informational / navigational / transactional / commercial).

### Tone & Style
- Write as a professional wine editor, not a marketer.
- Natural Korean flow — avoid translated-sounding or robotic AI phrasing.
- Paragraphs should be short enough for mobile reading.
- No keyword stuffing; integrate terms naturally.

### Forbidden
- Overhyped marketing words (최고, 혁신적, 독보적, etc. used as filler)
- Repetitive AI-template phrases
- Generic filler sentences that add no information
